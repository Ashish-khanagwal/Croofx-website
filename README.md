## 🚀 About Croofx

Croofx is a repo-aware AI execution engine that helps developers run LLMs on real-world codebases - safely, selectively, and predictably.

Instead of blindly sending entire repositories to an AI model, Croofx:

- Understands project structure
- Filters out irrelevant files
- Selects high-impact modules
- Validates AI-generated patches
- Reduces unnecessary token usage

LLMs generate. Croofx enforces discipline.
